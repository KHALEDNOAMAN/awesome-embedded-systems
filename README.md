## Dev Boards
- [Arduino](https://www.arduino.cc/) - Easy-to-use electronics platform.
- [ESP32](https://www.espressif.com/en/products/socs/esp32) - Low-power system on a chip with Wi-Fi & dual-mode Bluetooth.
- [STM32](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html) - 32-bit ARM Cortex-M microcontrollers.
- [RPi](https://www.raspberrypi.org/) - Small single-board computers.
- [FPGA](https://en.wikipedia.org/wiki/Field-programmable_gate_array) - Field-programmable gate array.

## RTOS
- [FreeRTOS](https://www.freertos.org/) - Market leading RTOS for microcontrollers.
- [Zephyr](https://zephyrproject.org/) - Scalable real-time operating system.
- [NuttX](https://nuttx.apache.org/) - Real-time operating system with an emphasis on standards compliance.

## IDEs/Toolchains
- [PlatformIO](https://platformio.org/) - Professional collaborative platform for embedded development.
- [Keil](https://www.keil.com/) - C/C++ compiler and debugger for ARM.
- [GCC ARM](https://developer.arm.com/tools-and-software/open-source-software/developer-tools/gnu-toolchain/gnu-rm) - GNU Arm Embedded Toolchain.

## Protocols
- I2C, SPI, UART, CAN, MQTT, BLE, LoRa

## Simulation
- [Wokwi](https://wokwi.com/) - Online Arduino and ESP32 Simulator.
- [Proteus](https://www.labcenter.com/) - PCB Design & Circuit Simulator Software.
- [QEMU](https://www.qemu.org/) - Generic and open source machine emulator and virtualizer.
